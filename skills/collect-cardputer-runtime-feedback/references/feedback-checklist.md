# Runtime feedback checklist

Request only the signals changed by the build:

- Exact header/status string and HTTP error number.
- Whether menu navigation moves and produces a tone.
- Whether Shift+`/` inserts `?` without navigating.
- Whether Space press begins recording and release stops it.
- Whether Enter replays locally, plus relative loudness and distortion.
- Whether `LIVE` reports Hetzner or offline.
